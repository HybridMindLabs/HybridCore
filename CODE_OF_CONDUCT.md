# Code of Conduct

HybridCore is built by a community of server owners, extension developers and
contributors. This document sets the standard for how people treat each
other in this repository — issues, pull requests, discussions and any other
project space.

---

## Our Standard

**Expected:**

- Be respectful of differing viewpoints and experience levels.
- Give and accept constructive feedback gracefully.
- Focus criticism on the code and the idea, not the person.
- Assume good faith before assuming malice or incompetence.
- Respect maintainers' time — search existing issues before opening a new one.

**Not tolerated:**

- Harassment, insults or personal attacks, public or private.
- Discriminatory language or behaviour of any kind.
- Publishing others' private information without consent.
- Sustained disruption of discussions, issues or pull requests.
- Any conduct that would reasonably be considered unprofessional.

---

## Scope

This applies everywhere a person represents the project: this repository
(issues, PRs, discussions, code review), any official community spaces
(Discord, forums), and any other setting where someone is acting as a
HybridCore contributor or maintainer.

---

## Reporting

Report a violation privately to the core team — the same contact used for
[security reports](SECURITY.md#reporting-a-vulnerability): a GitHub Security
Advisory, or the maintainer email listed on the repository profile. Do not
raise conduct issues in a public issue, PR or discussion.

Include what happened, where, and who was involved. Reports are handled
confidentially.

---

## Enforcement

| Violation | Response |
|---|---|
| First, minor incident | Private warning, explanation of what was wrong |
| Repeated or moderate incident | Temporary ban from repository interactions |
| Severe or repeated after warning | Permanent ban from the project |

Maintainers who don't follow or enforce this Code of Conduct in good faith
face the same consequences as any other contributor.
